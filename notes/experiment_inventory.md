# Final Experiment Evidence Inventory

## Scope and statistical conventions

- Evidence source: read-only repository `E:\projects_70`.
- No experiment, Docker topology, API call, model training, or dashboard validation was rerun.
- `REPOSITORY_REPORTED` identifies values already present in retained summaries.
- `AUDIT_COMPUTED` identifies values recomputed from complete retained per-run rows. Sample standard deviation and a two-sided Student's *t* 95% confidence-interval half-width are used.
- `DOCUMENTED_ONLY` identifies results stated in documentation when corresponding raw validation logs are not retained.
- Relative deviation is `(measured mean - configured value) / configured value`; it is used only where the quantities are directly comparable.
- Configured latency is one-way impairment. Measured ping RTT is an end-to-end round-trip observation and is not treated as a direct error against the configured delay.
- Configured packet loss is one-way impairment. Measured ping loss is end-to-end round-trip loss and is not treated as a direct error against the configured percentage.

## Status definitions

- `READY_FOR_MAIN_TEXT`: evidence supports a bounded dissertation claim in the main narrative.
- `READY_FOR_APPENDIX`: retained evidence is useful for provenance or implementation validation but is not a primary statistical result.
- `DOCUMENTED_ONLY`: a result is described in retained documentation but its raw validation log is absent.
- `INSUFFICIENT`: available evidence cannot support the intended bounded claim.

## Core evidence gaps

- The historical 20-Mbps result is one retained record and does not provide a repeated-run confidence interval.
- Bandwidth 50/100 and full-topology Germany50 evidence have no retained publication-ready plots.
- The Germany50 extracted-path repository summary uses population standard deviation; this inventory reports audit-computed sample standard deviation and Student's *t* confidence intervals.
- The RL repository confidence intervals use a different convention from the audit-computed small-sample intervals. Repository-reported RL values are preserved and explicitly labelled.
- Dashboard quantitative validation is documented, but raw UI-path, download, 69-test, security-scan, secret-scan and fresh-clone logs are not retained.
