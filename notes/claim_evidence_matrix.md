## Evidence-boundary checklist

| Boundary | Allowed wording | Disallowed wording |
|---|---|---|
| Germany50 routing | The 4,224-entry route plan was validated in dry-run mode. | All 4,224 routes carried real traffic. |
| Germany50 traffic | Real traffic was measured on three representative shortest/median/longest paths. | Germany50 was evaluated with all-pairs real traffic. |
| Germany50 extracted paths | Controlled Germany50-derived path experiments evaluated increasing hop counts. | Extracted-path experiments instantiated the full 50-node topology. |
| AI providers | Official OpenAI returned HTTP 429; a separate Qwen-compatible path succeeded. | The official OpenAI API succeeded. |
| RL result | The threshold heuristic outperformed the evaluated Q-learning configuration. | Q-learning was superior, optimal, or generally invalidated. |
| Dashboard | A bounded small-topology interface was implemented; its quantitative UI-path result is documented only. | The Dashboard manages full Germany50, trains RL, or permits arbitrary Docker execution. |
| Reproducibility | Retained scenarios, raw evidence, summaries, scripts, repeated runs, validation and cleanup support reproducibility. | A retained fresh-clone/security/secret-scan report exists. |

## Unsupported claims

None of the confirmed RQs, core claim, or contributions is unsupported when the boundaries above are preserved.
