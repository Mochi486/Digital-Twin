\section{Background and Related Work}
\label{sec:related-work}

\subsection{Network digital twins}

The Internet Research Task Force (IRTF) draft organizes NDT data, models, mappings, and interfaces, but is a work in progress rather than a standard \citep{zhou2026ndt}. International Telecommunication Union Telecommunication Standardization Sector (ITU-T) Recommendation Y.3090 specifies requirements and a layered closed-loop architecture \citep{itut2022y3090}. Almasan et al. demonstrate quality-of-service (QoS)-aware routing, while Hui et al. analyze fidelity, efficiency, and flexibility \citep{almasan2022ndt,hui2023digitaltwin}. These sources define the concept and model-centric opportunities; they do not determine the measured behaviour of this container implementation.

\subsection{Closest emulation and reproducibility systems}

Mininet runs hosts, switches, links, and real application code on one machine for software-defined networking (SDN) experiments \citep{lantz2010network}. Handigol et al. add runnable specifications and complete artifacts to container-based emulation \citep{handigol2012reproducible}. CORE supports real-time wired and wireless emulation, distributed execution, and connection to physical networks \citep{ahrenholz2008core}. These systems establish broad topology execution; this study instead evaluates controlled Docker measurements through one specific scenario-to-evidence path.

The closest Docker systems cover substantial emulation capability. MeDICINE uses Containernet to prototype containerized network functions across multiple points of presence (PoPs), with resource limits, link impairments, and orchestration interfaces \citep{peuster2016medicine}. Kathar\'a provides lightweight container-based network scenarios and reports comparative scalability and performance \citep{scazzariello2020kathara}. Their topology and container support is broader than the small forms tested here, so this dissertation does not claim a stronger emulator. Its question concerns integration of declared impairments, measured traffic, retained per-run evidence, and guarded AI/control extensions in one bounded Docker NDT.

Reproducibility is a separate capability from emulation breadth. Handigol et al. package executable experiments and artifacts \citep{handigol2012reproducible}; the pos framework scripts orchestration, measurement, evaluation, and artifact bundling for repeatable network experiments \citep{gallenmuller2021pos}. pos is the closest workflow comparator, but it is a general experiment methodology rather than an evaluation of this Docker NDT's impairment, topology, and guarded-automation pipeline. Appendix Table~\ref{tab:closest-work} compares topology, Docker support, impairment, artifacts, scale, and guarded automation directly.

\subsection{Impairment, topology, and automation}

Linux queueing discipline (qdisc) \texttt{netem} can impose delay and loss, but timer granularity, Transmission Control Protocol (TCP) queues, and qdisc placement influence observations \citep{iproute2netem}. Configured one-way conditions are therefore reported separately from ping round-trip time (RTT), end-to-end loss, and iperf3 throughput.

The Internet Topology Zoo supplies operator-derived graphs for structural studies \citep{knight2011topologyzoo}. Germany50 provides 50 nodes and 88 links here, but a graph alone proves neither installed routes nor exercised traffic. The evaluation separates instantiation, full route-plan dry-run validation, and selected-path real traffic.

Large language models (LLMs) have been studied for network configuration and management. LLM-NetCFG verifies generated configurations before application, and a broader review identifies reliability, security, and evaluation risks \citep{lira2025llmnetcfg,liu2025llmnetworking}. These risks motivate schema validation, semantic checks, allowlisted projection, and restricted execution.

Reinforcement learning (RL) can learn repeated control decisions. DeepRM compares learned resource management with heuristics \citep{mao2016deeprm}; NDT studies use evolutionary strategies or twin assistance to improve learning and safety \citep{guemes2022accelerating,cheng2025dtrl}. These results justify testing a learner against transparent policies, but do not predict superiority in the present small, ordered task.

\subsection{Gap synthesis}

Closest systems already support network emulation, Docker nodes, scaling, or reproducible experiment packaging. What remains unanswered is the main RQ for this bounded integration: whether one validated Docker execution-and-evidence pipeline can enforce and measure controlled conditions, then be reused across the tested topology and guarded automation extensions. The evaluation answers only that question and reports failures, confounds, and evidence limits alongside successful observations.
