\subsection{Configuration and measurement details}

The direct supplementary bandwidth cohorts used reverse TCP iperf3 for five seconds with server-side TBF. The 50-Mbps cohort has five valid attempts. The 100-Mbps result uses five valid measurements from six planned attempts; the failed record and run-06 retry are retained. The historical routed 20-Mbps value is one record only.

Latency used configured one-way delays of 0/10/30/50 ms with five runs and three ping packets per run. Packet loss used configured one-way probabilities of 0/1/3/5\% with five runs and 100 packets per run. For both experiments, measured end-to-end quantities are reported separately from configured one-way impairments.

\subsection{AI and Dashboard boundaries}

The AI execution chain comprises structured generation, schema validation, semantic validation, prompt-constraint checking, projection to an executable scenario, dry-run, and controlled Docker execution. Official OpenAI returned HTTP 429 \texttt{insufficient\_quota}; a separate Qwen-compatible provider completed validation. The provider distinction must be preserved in any extracted result or presentation.

The Dashboard supports bounded small-topology interaction. Its documented run \texttt{3cada000bb4d} used 20 Mbps, zero delay/loss, three pings, and three seconds of iperf3. Documentation reports 3/3 replies, 0.101/0.118/0.143-ms RTT, 19.4 Mbps, successful downloads, and cleanup. Raw UI-path, 69-test, security, secret-scan, and fresh-clone validation logs were not retained, so these checks are not presented as independently auditable evidence.

\subsection{Reproduction boundary}

The repository includes scenarios, scripts, evidence summaries, and a reproducibility guide. Re-running the formal matrices is neither necessary nor part of this dissertation preparation workflow. A future independent replication should record host/kernel/Docker versions, image digests, complete stdout/stderr, resource utilization, and fresh-clone validation, then compare its new results without overwriting the sealed evidence used here.
