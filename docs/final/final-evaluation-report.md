# Final evaluation report

Germany50 was instantiated as 50 containers and 88 networks. The selected-route full deployment installed 20 batched routes rather than the 4,224-entry theoretical plan, and all three selected paths completed three ping/iperf runs.

RL uses five fixed synthetic seeds plus four real Docker episodes with verified route changes, ping, iperf and cleanup. The threshold heuristic remains stronger than Q-learning across the available seed results.
